## Statement of Ethical AI Use

I used AI as a **coding assistant and learning tool**, not as a replacement for my own understanding.

**Key principles I followed:**

1. **Leveraged prior experience** - My work on the Budgie app gave me a foundation in Firebase and documentation that I built upon

2. **No copy-paste without understanding** - Every line of AI-generated code was reviewed and understood before being added to the project

3. **Customization is key** - AI provided templates; I customized them for MzansiBuilds specific requirements

4. **Debugging is learning** - When AI helped fix errors, I made sure to understand why the error occurred

5. **Documentation transparency** - This document exists to be transparent about AI usage and prior experience

6. **Code ownership** - I can explain every line of code in this project and make changes confidently

## Conclusion

My previous experience with the Budgie app gave me a head start on Firebase integration and documentation structure. AI accelerated my development process further and helped me learn new React patterns. However, all final code represents my work, decisions, and understanding. The MzansiBuilds platform is a product of my prior knowledge, human creativity, and guided AI assistance.
